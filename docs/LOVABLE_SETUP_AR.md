# إعداد Lovable — Ahmed Maaroof Agent OS

## الدور المقترح
استخدم Lovable لبناء واجهة المستخدم وإدارة تجربة الاستخدام. لا تنقل مفاتيح OpenRouter أو مفاتيح Supabase السرية إلى الواجهة.

## إعداد الاتصال
1. افتح مشروع Lovable واربطه بمستودع الواجهة الذي ستعتمده.
2. اضبط عنوان API في متغير الواجهة العام `VITE_AGENT_API_URL` ليشير إلى FastAPI أو Edge Gateway.
3. لا تضع shared bearer token ثابتاً داخل JavaScript المنشور. للاختبار المحلي فقط يمكن تمرير token يدوياً إلى الحقل المخصص.
4. للإنتاج، استخدم Supabase Auth ثم Edge Function تتحقق من JWT وتحوّل الطلب إلى خدمة FastAPI خاصة.
5. قيّد CORS إلى نطاق Lovable/Vercel الفعلي، واستخدم HTTPS.

## ملاحظة حول الاستيراد
ربط Lovable بمستودع GitHub ليس ضماناً لاستيراد أي مشروع قائم تلقائياً. اختبر آلية الربط في مشروع Lovable الحالي قبل اعتمادها، ولا تسمح بإنشاء مستودع بديل دون التأكد من مسار المزامنة.

## متغيرات الخادم
- `AGENT_API_KEY`: سر FastAPI.
- `OPENROUTER_API_KEY`: مفتاح مزود النماذج.
- `SUPABASE_SERVICE_ROLE_KEY`: سر خادمي فقط، إن استُخدم.

لا تضف أيّاً من هذه القيم إلى متغيرات `VITE_*`.
