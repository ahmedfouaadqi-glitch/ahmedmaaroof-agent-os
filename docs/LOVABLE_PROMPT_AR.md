# Prompt البناء الأساسي داخل Lovable

أنشئ واجهة احترافية ثنائية اللغة لمشروع Ahmed Maaroof Agent OS باستخدام React وTypeScript.

## متطلبات الواجهة
- دعم العربية والإنجليزية مع RTL/LTR تلقائياً.
- تصميم Dark Glassmorphism هادئ، واضح، عملي ومتجاوب.
- مساحة محادثة مركزية مع سجل الرسائل وحالة تنفيذ واضحة.
- أقسام منفصلة للمحادثة، الذاكرة، المهارات، المشاريع والإعدادات.
- إعدادات API قابلة للتغيير من شاشة إعدادات آمنة.
- رسائل خطأ صريحة عند انقطاع API أو رفض المصادقة.
- لا تعرض أزرار تنفيذ لمهارات غير مفعّلة.

## تكامل API
استخدم FastAPI endpoints:
- GET `/v1/health`
- GET `/v1/skills`
- GET `/v1/system/stats`
- POST `/v1/chat`
- POST `/v1/memory/search`
- POST `/v1/memory/ingest-vault`

لا تخزّن أسرار مشتركة في كود المتصفح. في الإنتاج مرّر الهوية عبر Supabase Auth وEdge Function موثقة تتحقق من JWT.

## معايير القبول
- اتجاه النص يتغير مع اللغة.
- لا يفقد سجل المحادثة عند إعادة التصيير.
- حالات التحميل والخطأ والاتصال ظاهرة.
- الواجهة تعمل على الهاتف والحاسوب.
- لا تدّعي نجاح تنفيذ مهارة إلا عند استلام نتيجة موثوقة من الخادم.
