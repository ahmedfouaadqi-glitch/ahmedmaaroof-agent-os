# حالة تطوير Agent OS — النواة التشغيلية

## ما أضيف في هذه المرحلة
- Orchestrator واضح بمسار Plan → Retrieve → Route → Execute → Reflect.
- اختيار مهارة أولي قابل للتجاوز الصريح عبر skill_id.
- مهارات عامة وبحث سوق وصناعة محتوى وتخطيط سير عمل.
- إبقاء مهارات إدارة النظام وجمع البيانات معطلة.
- تعريفات أتمتة محفوظة في SQLite مع إنشاء/عرض/تفعيل/تعطيل/حذف.
- حالة تكاملات البريد والتقويم والصوت والمصمم دون الادعاء بأنها متصلة.
- Whisper وKokoro ممثلان كخدمات محلية اختيارية، ولا يتم إرسال الصوت إلى مزود خارجي تلقائياً.

## حدود مهمة
- الأتمتة في هذا الإصدار تحفظ التعريفات فقط؛ لا يوجد Scheduler/Worker يطلقها في الخلفية بعد.
- البريد والتقويم يحتاجان OAuth أو Connector موثوقاً، ولم تتم مصادقة أي حساب.
- الصوت يحتاج تشغيل Whisper وKokoro كخدمتين محليتين وتحديد بروتوكول API؛ إعداد URL وحده لا يثبت جاهزية الخدمة.
- المصمم يحتاج مزود صور/فيديو فعلياً وسياسة تكلفة وموافقة قبل التوليد.
- لا يتم اختيار أو استيراد أو فهرسة أي مصدر معرفة جديد في هذا التغيير. واجهات الذاكرة الحالية باقية دون تغيير في مصدرها.
- لا يوجد نشر إنتاجي أو مفاتيح حقيقية مضافة إلى المستودع.

## API
- GET /v1/integrations/status
- POST /v1/agent/run
- GET/POST /v1/automations
- PATCH/DELETE /v1/automations/{automation_id}

## المتطلبات قبل الإنتاج
1. إضافة Scheduler/Worker مستمر مع قفل وتكرار آمن وسجل تنفيذ.
2. OAuth وتخزين آمن للتوكنات للبريد والتقويم.
3. عقد API موحد لخدمات الصوت المحلية والتحقق من health/readiness.
4. مزود تصميم مع quotas ومراجعة بشرية.
5. مصادقة مستخدمين متعددة وعزل بيانات ومساحات عمل وrate limiting.
