## الأولويات التالية
1. إكمال وربط واجهة Lovable مع API عبر بوابة آمنة ذات هوية مستخدم.
2. اختبار المصادقة وتحديد المعدلات وعزل بيانات المستخدمين.
3. إضافة سجلات تنفيذ وموافقات قبل أي إجراء خارجي.
4. تشغيل الاختبارات والبناء في CI، ثم نشر تجريبي.
5. تفعيل RAG الدلالي بعد قياس جودة الاسترجاع وتكلفته.
